2. ARCHITECTURE
----------------------------------------------------------------
A custom Node/TS failover layer for Solana (Docker, :4100):

  Solana  --->  multi-provider auto-failover on 429/error,
                cooldown + retry/backoff, per-provider stats
                    |
                    +--> USDC deposit indexer
                    +--> HTTP gateway (Postman/curl ready)

Providers in priority order:
  helius (primary) -> publicnode -> solana-public
  (drpc / ankr configurable but disabled: free endpoints returned
   HTTP 400 / 403 as of 2026-08)

DB: Optional. A cache DB is not required to meet the objectives.
Can add Redis cache later if desired (Postgres not needed).


3. TEST RESULTS
----------------------------------------------------------------

--- 3.1 Solana fallback RPC ---
Gateway healthy with providers in priority order:
  helius (primary) -> publicnode -> solana-public
  (drpc / ankr disabled: free endpoints returned HTTP 400 / 403)

  => Any provider that rate-limits or errors is put on cooldown
     and traffic automatically fails over to the next one.
  => Every response carries an X-RPC-Provider header showing
     which provider served it.


--- 3.2 Rate-limit + failover test (KEY RESULT) ---

PHASE A - Hammer ONE provider directly, NO failover:
  60 concurrent requests x 4 rounds against solana-public
  Result: 200 of 240 requests throttled (429)
  => 83.3% rate-limited. Confirms the real rate limit exists.

PHASE B - Same load THROUGH the failover client:
  60 concurrent requests x 4 rounds
  Result: 240 of 240 succeeded
  Failover events: 63 | rate-limit events: 63
  Per-provider: solana-public 60 req / 60x 429 (throttled),
                helius 120 req / 117 ok / 3x 429,
                publicnode 123 req / 123 ok

  => End-to-end success rate WITH failover: 100.0%
  => VERDICT: PASS. The fallback mechanism absorbed the rate
     limiting and kept every request succeeding.


--- 3.3 USDC deposit indexing (given wallet addresses) ---
Indexer diffs each transaction's pre/post USDC token balances
(raw integer math, no floating-point error) to detect deposits.

  Address: G9L3ac8qYKNy1gTxdmhxTbDVyGHf5NAaSDYzvkgitVLJ
  Result:  received 344.088645 USDC  (30 deposits)
  Note:    FULL HISTORY - this wallet's USDC account has 61
           signatures, all scanned. This is the confirmed
           lifetime total.

  (Very high-volume wallets, e.g. 40k+ signatures, need a paid
   Helius tier / Enhanced API for full-history scans; the indexer
   logic itself is proven correct on the complete G9L3 example.)

Data verified as real Solana mainnet:
  - our gateway's results match the official Solana endpoint
    byte-for-byte
  - slot advances live (~1 block / 0.4s), confirming a live chain
  - all values cross-checkable on solscan.io

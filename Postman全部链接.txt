  Postman 全部测试链接 (Links)
================================================================

系统有三个入口:
  统一网关(接待员) -> http://localhost:8080   ★推荐,一个地址通吃
  eRPC (ETH/BSC)   -> http://localhost:4000   (后端)
  Solana           -> http://localhost:4100   (后端)

先确认都在跑(浏览器打开):
  http://localhost:8080/health   看到 erpc 和 solana 都 ok 就正常


================================================================
  Postman 通用步骤
================================================================
1. New -> HTTP
2. 选方法 (POST / GET, 下面每条会标)
3. 地址栏贴 URL
4. POST 才需要: Body -> raw -> JSON -> 贴 body
5. Send
6. 看返回 Headers 里的 X-RPC-Provider (哪个数据源服务的)

★ 规律:
  带 body 的查询(getSlot/eth_blockNumber等) 用 POST
  带路径的(/health /stats /block /address /usdc/) 用 GET

================================================================
  四、USDC 转账返回的字段 (L6/L7/L9/L10/L24/L25)
================================================================
  direction 方向 (in收到 / out转出, 仅 /address 有)
  from      转出方地址
  to        收款方地址
  amount    金额
  unit      单位 (USDC)
  price     实时美元价 (约 $1.00, 从 CoinGecko 拉)
  valueUsd  美元价值 = amount x price
  block     区块号
  signature/tx  交易签名/哈希


================================================================
  五、给老板演示重点截图

================================================================
  常见错误
================================================================
错误: "Use POST with a JSON-RPC body, or GET /health, GET /stats"
  -> 根地址用了 GET, 改成 POST 并贴 body

错误: (405) Method Not Allowed
  -> 方法用反了, 对照上面每条标的 POST/GET

错误: 连不上 / Could not send request
  -> 服务没开, PowerShell 执行:
     cd C:\Users\USER\erpc\solana       ; docker compose up -d
     cd C:\Users\USER\erpc\gateway      ; docker compose up -d
     cd C:\Users\USER\erpc\gateway-proxy; docker compose up -d

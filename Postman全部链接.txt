================================================================
  Postman 全部测试链接 (Links) - Solana Gateway
================================================================

服务地址: http://localhost:4100
容器: solana-gateway (Docker, 后台运行)

先确认服务在跑(浏览器打开):
  http://localhost:4100/health
  看到 {"status":"ok","providers":[...3个...]} 就是正常


================================================================
  Postman 通用步骤
================================================================
1. New -> HTTP
2. 选方法 (POST / GET, 下面每条会标)
3. 地址栏贴 URL
4. POST 才需要: Body -> raw -> JSON -> 贴 body
5. Send
6. 看返回 Headers 里的 X-RPC-Provider (哪个数据源服务的)

★ 规律:
  根地址 http://localhost:4100/  用 POST (要贴 body)
  带路径的 (/health /stats /block /address) 用 GET (不贴 body)


================================================================
  一、基础检查
================================================================

--- L1 健康检查 ---
GET  http://localhost:4100/health
功能: 确认 Solana 网关在运行, 并列出 3 个数据源
      (helius, publicnode, solana-public)
      (drpc / ankr 已停用: 免费端点返回 HTTP 400 / 403)

--- L2 各数据源使用统计 ---
GET  http://localhost:4100/stats
功能: 显示每个数据源被用了多少次、成功/被限流(429)多少次。
      用来观察 fallback(自动换源)有没有在工作。

================================================================
  三、★核心: USDC 转账查询 (from/to/block/price/单位)
================================================================

--- L7 ★某地址 USDC 转账 (from/to/block/price/单位) ---
GET  http://localhost:4100/address/G9L3ac8qYKNy1gTxdmhxTbDVyGHf5NAaSDYzvkgitVLJ?limit=30
      limit=扫最近多少笔(默认25, 最大200)

--- L8 ★某区块 USDC 转账 (from/to/block/price/单位) ---
GET  http://localhost:4100/block/435464598

--- L9 某区块 + 只看某地址 ---
GET  http://localhost:4100/block/435464598?address=6LY1JzAFVZsP2a2xKrtU6znQMQ5h4i7tocWdgrkZzkzF


================================================================
  四、任意 Solana 查询 (带 fallback)
================================================================

--- L10 任意 Solana JSON-RPC ---
POST http://localhost:4100/
Body: 任何标准 Solana JSON-RPC, 例如 getSlot / getBalance /
      getSignaturesForAddress / getTransaction / getBlock 等
功能: Solana 万能入口, 自动享受 5 源 fallback。
      ★发完看返回 Headers 里的 X-RPC-Provider, 就知道是
        哪个数据源服务的(证明 fallback)。


================================================================
  五、USDC 转账返回的字段 (L7/L8/L9)
================================================================
  direction 方向 (in收到 / out转出, 仅 /address 有)
  from      转出方地址
  to        收款方地址
  amount    金额
  unit      单位 (USDC)
  price     实时美元价 (约 $1.00, 从 CoinGecko 拉)
  valueUsd  美元价值 = amount x price
  block     区块号
  signature 交易签名


================================================================
  六、给老板演示重点截图
================================================================
  L7 或 L8   -> Solana 钱包/区块 USDC 转账 (from/to/block/price/单位)
  L1         -> 3 个数据源都健康

  演示 fallback:
  先 L2(/stats)只有helius -> 快速连发很多次 L3 -> 再 L2 出现 publicnode


================================================================
  常见错误
================================================================
错误: "Use POST with a JSON-RPC body, or GET /health, GET /stats"
  -> 根地址用了 GET, 改成 POST 并贴 body

错误: (405) Method Not Allowed
  -> 方法用反了, 对照上面每条标的 POST/GET

错误: 连不上 / Could not send request
  -> 服务没开, PowerShell 执行:
     cd C:\Users\USER\erpc\solana ; docker compose up -d
